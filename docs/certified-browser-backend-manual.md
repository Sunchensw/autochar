# 已认证后台录制手册

本手册适用于京东、唯品会、抖店、天猫、企业内部门户等会校验浏览器环境、登录状态或软件来源的后台。前提是用户已经获得授权，并且能在自己的浏览器中正常登录和操作。

## 推荐流程

1. 启动 Autochar Recorder：`npm run recorder`。
2. 进入“扩展录制”。
3. 点击“获取扩展连接信息”。
4. 点击“打开扩展目录”，在 Chrome 或 Edge 的扩展管理页加载该目录。
5. 在扩展弹窗中填入 Recorder 显示的 Receiver 和 Token，并测试连接。
6. 回到 Recorder，点击“开始扩展录制”。
7. 用户在已授权后台页面按真实业务步骤操作。
8. 回到 Recorder，点击“停止录制”。
9. 在“AI 文档”确认预览内容。
10. 点击“导出 .autochar.md”。

## 文档交付

最终只需要交付一个 Markdown 文件。文档会包含页面结构摘要、自然语言步骤、selector 候选、变量表、风险提示和可解析的 `Structured Data` JSON。

## 安全说明

- 只记录用户实际操作过的页面结构和动作说明。
- 不写入密码值、验证码值、令牌、站点凭据或浏览器本地/会话存储。
- 遇到验证码、风控、二次验证、登录失效时，文档会明确提示人工介入。
- 文档不是脚本，不会自动执行后台操作。
