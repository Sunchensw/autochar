# 京东等认证浏览器环境后台使用手册

本手册适用于京东、唯品会、抖店、天猫、企业内部门户等会校验浏览器环境、登录状态或软件来源的后台。目标是在用户已经获得授权、已经能正常登录后台的前提下，用 Autochar Recorder 录制操作流程，并导出 `.flow.zip` 给运营端复核和批量执行。

## 一、为什么要用扩展录制

部分后台会识别 Playwright 新打开的 Chromium，并提示“未用认证软件”“浏览器环境异常”或要求重新认证。遇到这种情况，不要继续在 Playwright Chromium 里登录，也不要尝试伪装、绕过或隐藏自动化特征。

正确做法是使用 **Chrome/Edge 扩展录制**：

- 用户仍然在自己平时使用、已经通过平台认证的 Chrome/Edge 里打开后台。
- Autochar 扩展只捕获用户主动点击、输入、选择和页面跳转等操作。
- Electron 本地程序只接收扩展发来的步骤，生成和原来一致的 `flow.json`、截图、审核文本和 `.flow.zip`。
- 整个过程不导出 cookie、localStorage、sessionStorage、token、密码或验证码。

## 二、准备工作

确认以下条件都满足后再开始：

1. 用户已经获得目标后台操作授权。
2. 用户自己的 Chrome 或 Edge 已能正常登录目标后台。
3. Autochar Recorder 已安装或可通过 `npm run recorder` 启动。
4. 浏览器允许加载本地解压扩展。
5. 录制期间只操作本次要录制的目标后台页面，避免把无关页面动作录进去。

## 三、安装扩展

开发环境下扩展目录为：

```text
E:\AIpython\autochar\apps\recorder-extension
```

安装步骤：

1. 打开 Chrome 或 Edge。
2. 进入扩展管理页：
   - Chrome: `chrome://extensions`
   - Edge: `edge://extensions`
3. 打开“开发者模式”。
4. 点击“加载已解压的扩展程序”。
5. 选择 `apps/recorder-extension` 目录。
6. 浏览器工具栏出现 Autochar Recorder 扩展后，建议将它固定到工具栏。

## 四、连接 Autochar Recorder

1. 启动 Autochar Recorder。
2. 点击“开始扩展录制”。
3. 在 Recorder 页面复制：
   - 本地接收地址，例如 `http://127.0.0.1:17321`
   - 连接令牌
4. 点击浏览器工具栏里的 Autochar Recorder 扩展图标。
5. 填入本地接收地址和连接令牌。
6. 勾选“启用录制桥接”。
7. 点击“保存”。
8. 点击“测试连接”，看到“连接正常，可以开始录制”后再继续。

连接令牌用于防止其他本机网页随意向 Recorder 投递步骤。每次重新打开 Recorder 后，令牌可能会变化；如果扩展连接失败，重新复制新令牌即可。

## 五、录制流程

推荐按下面顺序录制：

1. 在 Chrome/Edge 中打开目标后台，并确认已经登录。
2. 进入本次流程的起始页面，例如商品列表、内容创建页、订单列表页。
3. 回到 Autochar Recorder，点击“开始扩展录制”。
4. 在目标后台页面按真实业务步骤操作。
5. 操作完成后，回到 Autochar Recorder，点击“停止录制”。
6. 查看步骤数、截图数、最后动作和审核文本。
7. 填写流程名称和备注。
8. 点击“导出 .flow.zip”。

建议流程名称写清楚平台和动作，例如：

```text
京东商品标题修改
京东商品主图更换
唯品会图文种草发布
```

备注建议包含：

- 授权范围
- 测试账号或店铺名称
- 哪些步骤需要人工复核
- 是否包含保存、发布、删除、改价等高风险动作
- 是否遇到验证码、短信验证、登录失效或风控提醒

## 六、录制质量检查

导出前请检查：

1. 步骤数是否符合预期。
2. 第一个步骤是否是正确的起始页面。
3. 每个关键点击、输入、选择动作是否都被记录。
4. 截图是否能反映关键页面状态。
5. 密码、验证码等敏感输入没有明文出现在审核文本里。
6. 保存、发布、删除、改价、库存调整等动作是否被标记为高风险。
7. 备注里是否写清楚需要人工复核的地方。

如果发现步骤缺失，建议重新录制，不要手动拼接不确定的流程。

## 七、交给运营端复核

导出的 `.flow.zip` 通常包含：

```text
flow.json
metadata.json
notes.txt
review.md
screenshots/*.png
```

运营端处理顺序：

1. 打开 Autochar Operator Console。
2. 导入 `.flow.zip`。
3. 查看基础校验结果。
4. 复核步骤、selector、敏感字段、高风险动作和截图。
5. 生成 Playwright 脚本。
6. 选择 CSV/XLSX 数据文件。
7. 先执行 dry-run。
8. 确认无误后，再勾选正式执行确认并运行正式任务。

## 八、常见问题

### 1. 扩展提示连接失败

处理方式：

1. 确认 Autochar Recorder 正在运行。
2. 确认已经点击“开始扩展录制”。
3. 重新复制 Recorder 页面里的本地接收地址和连接令牌。
4. 在扩展 popup 里保存后重新测试连接。
5. 如果端口被占用，Recorder 会自动尝试后续端口，以页面显示为准。

### 2. 步骤数一直是 0

可能原因：

- 扩展没有启用录制桥接。
- 扩展里填的是旧令牌。
- 当前页面没有加载扩展，例如浏览器限制了该站点扩展权限。
- 用户还没有在目标后台页面产生点击、输入或选择动作。

处理方式：

1. 点击扩展图标，确认“启用录制桥接”已勾选。
2. 点击“测试连接”。
3. 刷新目标后台页面。
4. 再执行一次简单点击或输入。

### 3. 截图没有正常显示

扩展会尽量通过浏览器的 `captureVisibleTab` 捕获当前可见页。如果浏览器拒绝截图，Recorder 会写入占位 PNG，避免导出流程被阻塞。

处理方式：

- 确认正在操作的后台标签页是当前激活标签页。
- 录制关键步骤时，不要切换到其他窗口或标签页。
- 如关键截图缺失，建议重新录制该流程。

### 4. 京东仍然提示环境异常

扩展录制不会改变京东后台的认证规则。它的作用是让用户继续使用自己已认证的浏览器环境，而不是用 Playwright Chromium 打开后台。

如果用户自己的 Chrome/Edge 也提示异常，请先按平台要求完成登录、认证或使用平台官方客户端。Autochar 不提供绕过认证、验证码、人机验证或风控检测的能力。

### 5. 输入密码或验证码会不会被记录

不会明文记录。Recorder 会根据字段类型、名称、标签和占位符识别敏感字段，并把值脱敏存储。验证码、短信验证、人机验证、登录失效等场景应由人工处理，不应自动化绕过。

## 九、安全边界

Autochar 扩展录制只用于用户已授权后台的流程记录和复核。不得用于：

- 绕过验证码、短信验证、人机验证或风控检测。
- 获取、导出或复用 cookie、token、localStorage、sessionStorage。
- 未经授权批量操作第三方后台。
- 规避平台的软件认证或安全策略。

遇到认证、风控、登录失效、二次验证等页面时，应暂停流程并交由人工处理。
