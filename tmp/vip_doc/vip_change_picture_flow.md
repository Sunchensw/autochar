每行数据处理流程：

1. 打开并固定商品资料页。
   进入起始 URL，等待商品资料列表页加载完成。
   该页面作为固定保留页，后续不要关闭。

2. 读取 Excel。
   默认只取第一行有效数据作为试跑数据。
   如果用户确认全量执行，再读取全部有效行。
   有效行判断：SKU码不为空，且至少一个图片路径字段不为空。

3. 批量取消提交审核。
   试跑模式下，只处理第一行有效数据的 SKU码。
   全量模式下，读取所有有效行的 SKU码，去重后按列粘贴，不要复制表头。
   在查询区域找到“款号/色号”输入框，填入 SKU码。
   点击“查询”。
   查询结果出现后，在商品列表中勾选商品信息旁边的全选复选框。
   参考元素：
   <span class="el-checkbox__inner"></span>
   点击“批量取消提交审核”按钮。
   参考元素：
   <span>批量取消提交审核</span>
   等待页面出现“操作成功”提示后，再开始逐条编辑商品。

4. 回到固定商品资料页。
   每处理一行数据前，都确认当前浏览器仍保留最开始的商品资料页。
   如果编辑页保存后跳转到了新的列表页，应关闭跳转页或切回固定商品资料页。

5. 查询当前 SKU。
   清空查询区域的“款号/色号”输入框。
   填入当前行 Excel 列“SKU码”的值。
   点击“查询”。
   等待查询结果刷新完成。
   如果查询不到 SKU，记录失败并跳过当前行。

6. 进入商品编辑页。
   在查询结果的右侧“操作”列点击“编辑”。
   等待商品编辑页加载完成。
   如果有多个查询结果，优先选择与当前 SKU码 完全匹配的商品行。

7. 滚动到商品图片区域。
   编辑页打开后，滚动到以下区域附近：

   - 商品图片

失败处理要求：
1. 每一行独立执行，单行失败不要中断整个 Excel。
2. 每处理一个 SKU/货号，都要记录处理状态：
   - 行号
   - SKU码
   - 货号
   - 是否进入编辑页成功
   - 实际处理了哪些图片类型
   - 哪些图片类型因路径为空被跳过
   - 是否保存成功
   - 如失败，记录失败原因和页面提示
   - 页面截图
3. 遇到以下情况不要继续盲目点击，先截图并记录原因：
   - 查询不到 SKU
   - 找不到“编辑”按钮
   - 找不到货号或 SKU 对应行
   - 找不到对应颜色
   - 图片路径不存在
   - 图片目录为空
   - 图片上传失败
   - 删除图片失败
   - 保存失败
   - 页面出现异常弹窗
4. 不要关闭最开始打开的商品资料页。
5. 不要点击“保存并提交审核”。
6. 只在确认当前 SKU/货号 保存成功后，再处理下一行。

特别注意：
1. 当前任务默认先试跑第一行有效数据，不要直接全量跑完整表。
2. 图片删除不能批量删除时，需要移动鼠标到每张图片上，逐个点击其下方删除按钮，直到该图片类型区域没有旧图片。
3. 图片路径是目录时，需要上传目录内图片；图片路径是文件时，只上传该文件。
4. 如果同一个 SKU码 对应多个货号，需要按 Excel 行逐行进入编辑页，根据“货号”选择对应颜色后分别保存。
5. “保存”和“保存并提交审核”可能相邻，定位保存按钮时必须精确匹配文本为“保存”的按钮。
