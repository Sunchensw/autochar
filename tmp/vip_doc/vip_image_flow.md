在 E:\AIpython\autotitle\autotitle\platforms\vipconpic 下新增或维护“唯品会发布图片种草内容”流程。该流程从 Excel 读取数据，使用用户已经登录的浏览器会话进入唯品会内容创作平台，按行创建图文种草内容，完成选择发布账号、填写标题、上传图片、填写正文、关联商品、设置主商品、设置定时上下线、选择标签，并提交审核。

录制文件中的 css=input、css=div、css=button、css=textarea 只能作为最后兜底，不要作为首选定位方式。

字段读取要求：
1. 读取 Excel 表头时需要 trim 前后空格。
   当前测试表中“内容正文”表头可能显示为“ 内容正文”，需要按去空格后的“内容正文”识别。
2. “图片地址”是图片所在目录，不是单个文件。
   当前测试 Excel 没有“文件名”列，因此需要读取“图片地址”目录下的图片文件并全部上传。
   支持图片后缀建议包括：.jpg、.jpeg、.png、.webp。
   多张图片按文件名自然排序后上传，避免顺序随机。
3. “定时上线”和“定时下线”如果被读取为 Excel 日期序列号，需要转换成页面可识别的时间文本。
   示例格式：
   2026-5-6 6:00:00
4. “标签”列可能使用换行、英文逗号、中文逗号分隔，需要先拆分、trim，再过滤空值。

每行数据处理流程：

1. 打开起始 URL。
   等待页面加载完成，确认已进入唯品会供应商管理平台的内容创作页面。
2. 切换到 iframe[name="vccp"]。
   后续大部分控件都应优先在该 iframe 内查找。
   如果中途弹窗、跳转或刷新导致定位失败，需要重新获取 iframe 后再继续。
3. 点击“立即创作”按钮。页面上有很多找所有可见的 .c-portal 卡片，然后只选卡片头部文字等于 图文 的那一块，再在这块里面找文字精确等于 立即创作 的按钮，不要有兜底，找不到图文的直接报错。
4. 选择发布账号。
   使用 Excel 列“发布账号”的值，匹配页面上的 radio 单选项。
   当前测试表常见值为：
   - 品牌种草官
   必须确认对应 radio 已选中后再继续。
5. 填写标题。
   使用 Excel 列“标题”的值。
   优先通过标题字段附近的 label、placeholder、表单区域或稳定属性定位输入框。
   录制中该步骤曾落到 css=input，但实现时不要直接填第一个 input。
   填写后确认页面输入框内的值与 Excel 一致。
6. 上传图片。
   点击“点击上传”按钮。
   使用 Excel 列“图片地址”作为目录，读取该目录下所有图片文件。
   实际上传路径应为：
   图片地址 + 每个图片文件名
   优先直接设置 input[type=file] 或 input[name=file] 的多个文件路径。
   如果页面必须弹出系统文件选择器，再使用 Windows 文件选择器兜底。
   上传后等待图片缩略图或上传完成状态出现，确认图片数量与本行目录中的图片数量一致。
7. 填写内容正文。
   使用 Excel 列“内容正文”的值。
   在图文正文 textarea 或对应文本框中填写。
   填写后确认页面文本框内的值与 Excel 一致。
8. 关联商品。
      在商品搜索框中输入 Excel 列“款号”的值。
      搜索框提示通常为：
      “请输入款号搜索关联商品，多个用英文逗号隔开”
      录制中稳定选择器包括：placeholder=请输入款号搜索关联商品，多个用英文逗号隔开  id=goods-search-input 
9. 输入后点击弹窗或区域中的“确认”按钮。等待商品关联成功。

11. 设置主商品。
      商品关联成功后，在商品卡片或商品行上点击“设为主商品”。
      点击后确认该商品已成为主商品，再继续。

12. 打开按时上下线。
      点击“按时上下线”开关。
      若开关已经打开，不要重复点击导致关闭。
      录制中该步骤曾落到 css=div，实现时需要优先通过开关附近文字“按时上下线”、role=switch、label 或相邻表单区域定位。

13. 设置上线时间。
      若 Excel 列“定时上线”不为空，在“请选择上线时间”输入框中填写该值。
      填写前如需清空已有值，只清空当前输入框，不影响其他字段。

14. 设置下线时间。
      若 Excel 列“定时下线”不为空，在“请选择下线时间，不填即长期”输入框中填写该值。
      注意：这里使用“定时下线”列，不要误用“定时上线”列。

15. 处理标签。
      使用 Excel 列“标签”的值。
      标签列可能包含多个标签，常见示例：
      珠宝首饰
      品牌页装修
      流入品牌动态

   标签分组映射：
   - 第 1 个标签：点击标签分组“一级品类（0/3）”，在“搜索便签”输入框中搜索并勾选该标签。
   - 第 2 个标签：点击标签分组“投稿场景-品牌装修页（0/1）”，在“搜索便签”输入框中搜索并勾选该标签。
   - 第 3 个标签：点击标签分组“投稿场景-品牌动态（0/1）”，在“搜索便签”输入框中搜索并勾选该标签。

   如果标签数量不足，缺失的标签步骤跳过。
   每次搜索前需要清空“搜索便签”输入框。
   勾选后需要确认对应 checkbox 已选中。
   搜索结果中如果有完全同名标签，优先选择文本完全匹配的项。

16. 提交审核前校验。
      点击提交前确认：
   - 发布账号已选择
   - 品牌号已选择或确认无需选择
   - 标题已填写
   - 图片已上传完成
   - 内容正文已填写
   - 商品已关联
   - 主商品已设置
   - 定时上线/下线已按 Excel 填写
   - 标签已按规则勾选

17. 点击“提交审核”按钮。
      提交后等待页面顶部或提示区域出现绿色成功提示。
      只有出现成功提示，才认为当前 Excel 行发布成功。

失败处理要求：
1. 每一行独立执行，单行失败不要中断整个 Excel。
2. 失败时记录：
   - 行号
   - 条码
   - 款号
   - 当前执行步骤
   - 错误原因
   - 页面截图
3. 若控件找不到，优先重新进入 iframe[name="vccp"] 并重新定位。
4. 不要依赖 css=button、css=input、css=div 这类模糊选择器作为首选。
   优先使用：
   - role
   - label
   - placeholder
   - 文本内容
   - 稳定 id
   - input[type=file]
5. 所有关键操作后都要做结果确认，例如 radio 是否选中、文本是否填入、图片是否上传完成、标签是否已勾选、商品是否已设为主商品。

特别注意：
1. 如果 Excel 中某字段为空，只跳过该字段对应动作，不要清空页面已有内容。
2. 当前测试 Excel 的“图片地址”目录必须真实存在；如果目录不存在或目录内没有图片，需要记录失败并跳过该行。
