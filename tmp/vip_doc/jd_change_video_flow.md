任务目标：
在 E:\AIpython\autotitle\autotitle\platforms\jd 下新增或维护“京东换视频/关联视频”流程。该流程从 Excel 读取数据，使用用户已经登录的浏览器会话进入京东商家后台图片/视频管理页面，按行上传或选择视频，进入视频使用页面，按 SKU 查询商品，勾选目标商品，并点击“关联”，完成商品与视频的绑定。

重要限制：
1. 本任务需要优先查看已登录浏览器中的页面结构，准确识别控件、按钮、输入框、上传组件、视频列表、商品列表和关联按钮，减少盲点点击。

2. 上传文件优先直接设置 input[type=file] 的文件路径。如果页面必须弹出系统文件选择器，再使用 Windows 文件选择器兜底。

3. 京东图片/视频管理页面录制中未发现 iframe，主要操作区域默认在当前页面；如果实际页面存在 iframe，需要先切换到对应 iframe 后再操作。

4. Excel 某一列为空时，该字段对应步骤跳过，不要填入空值，也不要清空页面已有内容。

5. 每一项操作应该设置等待时间，模拟人类操作，防止触发风控。

6. 表格有多行数据时，一行数据失败不要直接中断程序，需要返回报错信息并跳过该行，继续执行下一条数据。

7. 录制中的 css=input、css=button、css=a 只能作为最后兜底，不要作为首选定位方式。

字段读取要求：
1. 读取 Excel 表头时需要 trim 前后空格。

2. “视频地址”是视频所在目录，“文件名”是视频文件名。
   实际上传路径应为：
   视频地址 + 文件名
   示例：
   C:\Users\15842\Desktop\test\context\发布内容视频\轻版.MP4

3. 视频文件必须真实存在。
   支持视频后缀建议包括：.mp4、.mov、.avi、.mkv、.wmv。
   如果视频文件不存在，需要记录失败并跳过当前行。

4. “SKU码”用于进入视频使用页面后查询并关联商品。
   如果 SKU码 为空，当前行无法关联商品，需要记录失败并跳过。

5. “标题”“话题”“标签”不是本次录制中确认过的必填控件。
   如果后续页面上传视频时出现视频标题、话题或标签输入区，可以按这些字段填写；如果页面没有对应控件，则跳过，不要盲目点击。

每行数据处理流程：

1. 打开起始 URL。
   等待页面加载完成，确认已进入京东商家后台“图片/视频管理”页面。
   页面标题通常为：
   图片/视频管理

2. 准备当前行视频文件。
   读取 Excel 列“视频地址”和“文件名”。
   拼接成完整视频路径。
   检查文件是否存在。
   如果任一字段为空或文件不存在，记录失败并跳过当前行。

3. 点击“上传视频”按钮。
   录制中稳定选择器：
   role=button name=上传视频
   点击后等待上传弹窗、上传区域或 input[type=file] 出现。

4. 上传视频。
   优先直接设置 input[type=file] 的文件路径为当前行完整视频路径。
   如果页面必须弹出系统文件选择器，再使用 Windows 文件选择器兜底。
   上传后需要等待视频上传完成和转码/处理完成。
   等待方式应优先轮询页面状态，例如上传进度消失、上传成功提示、视频列表出现新视频、或可进入使用页面。

5. 进入视频使用页面。
   上传完成后，进入当前视频对应的使用/关联页面。
   录制中的目标页面格式为：
   https://media.shop.jd.com/app/html/use.html?videoId=2196425755&videoType=1
   如果上传完成后没有自动跳转，需要在视频列表中找到当前上传的视频，再点击对应的“使用”“关联商品”或类似入口。
   定位视频时优先使用文件名或标题匹配，不要点击页面上的第一个 input。

6. 在使用页面填写 SKU。
   使用 Excel 列“SKU码”的值。
   在占位提示为“请输入内容”的文本框中填写 SKU码。
   录制中稳定选择器：
   role=textbox name=请输入内容
   placeholder=请输入内容
   填写后确认输入框内的值与 Excel 一致。

7. 点击“查询”。
   录制中稳定选择器：
   role=link name=查询
   点击后等待商品列表刷新完成。
   如果查询不到商品，记录失败并跳过当前行。

8. 勾选目标商品。
   在查询结果中找到与当前 SKU码 完全匹配的商品行。
   勾选该商品行对应的 checkbox 或 input。
   录制中该步骤曾落到 css=input，实现时不要直接点击第一个 input。
   必须先定位到匹配 SKU 的商品行，再点击该行内的选择框。
   勾选后确认该商品已选中。

9. 点击“关联”。
   录制中稳定选择器：
   role=link name=关联
   点击后等待页面出现关联成功提示，或等待商品与视频绑定状态更新。
   只有确认关联成功，才认为当前 Excel 行处理成功。

10. 返回视频列表或准备下一行。
   当前行处理完成后，回到图片/视频管理列表页或重新打开起始 URL。
   继续处理下一行数据。
   如果页面仍停留在 use.html 页面，也可以直接打开起始 URL，避免继承上一条视频状态。

失败处理要求：
1. 每一行独立执行，单行失败不要中断整个 Excel。
2. 失败时记录：
   - 行号
   - SKU码
   - 视频地址
   - 文件名
   - 当前执行步骤
   - 错误原因
   - 页面截图
3. 遇到以下情况不要继续盲目点击，先截图并记录原因：
   - 视频文件不存在
   - 找不到“上传视频”按钮
   - 找不到 input[type=file] 或上传入口
   - 视频上传失败
   - 视频转码/处理超时
   - 无法进入 use.html 使用页面
   - 查询不到 SKU
   - 找不到 SKU 对应商品行
   - 商品勾选失败
   - 点击“关联”后没有成功提示
   - 页面出现登录失效、验证码、风控或异常弹窗
4. 不要依赖 css=button、css=input、css=a 这类模糊选择器作为首选。
   优先使用：
   - role
   - label
   - placeholder
   - 文本内容
   - 稳定 id
   - input[type=file]
   - 商品行内精确匹配 SKU 后再定位子元素
5. 所有关键操作后都要做结果确认，例如视频是否上传完成、SKU 是否填入、商品是否查询出来、目标商品是否已勾选、关联是否成功。

特别注意：
1. 如果 Excel 中某字段为空，只跳过该字段对应动作，不要清空页面已有内容。
2. 当前录制步骤较少，且第 3 步和第 7 步都记录为 css=input，不能机械照搬；必须先根据页面结构确认具体含义。
3. 上传视频后生成 use.html 页面可能需要等待，不能只用固定 sleep，应使用轮询等待页面状态或 URL 变化。
4. 如果同一个视频需要关联多个 SKU，可以按 Excel 多行处理；每行只关联当前行 SKU码。
5. 如果页面上传后要求填写标题，优先使用 Excel 列“标题”；如果没有标题控件，不要额外创建动作。
