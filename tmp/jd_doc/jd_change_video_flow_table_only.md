任务目标：
在 E:\AIpython\autotitle\autotitle\platforms\jd 下新增或维护“京东换视频/关联视频”流程。该流程只读取 Excel 表格中已有字段，使用用户已经登录的浏览器会话进入京东商家后台图片/视频管理页面，按行根据“视频地址”进入或定位目标视频，再使用“SKU码”查询商品，勾选目标商品并点击“关联”，完成商品与视频的绑定。

重要限制：
1. 本任务需要优先查看已登录浏览器中的页面结构，准确识别控件、按钮、输入框、视频列表、商品列表和关联按钮，减少盲点点击。

2. 本流程只处理测试 Excel 中实际存在的字段：
   - SKU码
   - 视频地址
   不要额外处理标题、话题、标签、文件名、发布时间等表格中不存在的字段。

3. 京东图片/视频管理页面录制中未发现 iframe，主要操作区域默认在当前页面；如果实际页面存在 iframe，需要先切换到对应 iframe 后再操作。

4. Excel 某一列为空时，该字段对应步骤跳过，不要填入空值，也不要清空页面已有内容。

5. 每一项操作应该设置等待时间，模拟人类操作，防止触发风控。

6. 表格有多行数据时，一行数据失败不要直接中断程序，需要返回报错信息并跳过该行，继续执行下一条数据。

7. 录制中的 css=input、css=button、css=a 只能作为最后兜底，不要作为首选定位方式。

https://media.shop.jd.com/app/html/list.html?videoType=1

测试 Excel：
C:\Users\15842\Desktop\test\jd换视频.xlsx

Excel 字段：

字段读取要求：
1. 读取 Excel 表头时需要 trim 前后空格。

2. “SKU码”是必须字段，用于在视频使用页面查询并关联商品。
   如果 SKU码 为空，当前行无法处理，需要记录失败并跳过。

3. “视频地址”只用于定位当前行要关联的目标视频。
   该字段可能为空，也可能是以下形式之一：
   - 京东视频使用页 URL，例如：
     https://media.shop.jd.com/app/html/use.html?videoId=xxxx&videoType=1
   - 京东视频列表页或视频详情页 URL
   - 本地视频文件路径

4. 如果“视频地址”为空：
   - 不要上传视频，也不要尝试填写空值。
   - 如果当前浏览器已经在某个 use.html 视频使用页面，可以直接使用当前页面关联该行 SKU。
   - 如果当前页面不是 use.html，且无法确定目标视频，需要记录失败并跳过该行。

5. 如果“视频地址”是 URL：
   - 优先直接打开该 URL。
   - 如果打开后不是 use.html 使用页面，需要在页面中查找“使用”“关联商品”或类似入口进入 use.html。

6. 如果“视频地址”是本地视频文件路径：
   - 需要先确认文件存在。
   - 打开起始页面后点击“上传视频”，上传该视频文件。
   - 上传完成后进入该视频对应的 use.html 使用页面。
   - 如果文件不存在，记录失败并跳过当前行。

每行数据处理流程：

1. 读取当前行数据。
   读取 Excel 列“SKU码”和“视频地址”。
   若 SKU码 为空，记录失败并跳过当前行。

2. 准备目标视频使用页面。
   根据“视频地址”字段分三种情况处理。

   情况 A：视频地址为空
   - 判断当前浏览器页面是否已经是京东视频 use.html 使用页面。
   - 如果是，继续执行商品查询和关联。
   - 如果不是，记录失败：视频地址为空且当前页面不是视频使用页面。

   情况 B：视频地址是 URL
   - 打开该 URL。
   - 等待页面加载完成。
   - 如果 URL 或页面已进入 use.html，继续下一步。
   - 如果仍是列表页或详情页，需要在当前视频对应区域点击“使用”“关联商品”或类似入口，进入 use.html。

   情况 C：视频地址是本地文件路径
   - 打开起始 URL。
   - 点击“上传视频”按钮。
   - 录制中稳定选择器：
     role=button name=上传视频
   - 等待上传弹窗、上传区域或 input[type=file] 出现。
   - 优先直接设置 input[type=file] 的文件路径为“视频地址”。
   - 如果页面必须弹出系统文件选择器，再使用 Windows 文件选择器兜底。
   - 上传后等待视频上传完成和转码/处理完成。
   - 上传完成后进入该视频对应的 use.html 使用页面。

3. 确认处于视频使用页面。
   页面 URL 通常类似：
   https://media.shop.jd.com/app/html/use.html?videoId=2196425755&videoType=1
   如果无法进入 use.html，记录失败并跳过当前行。

4. 在使用页面填写 SKU。
   使用 Excel 列“SKU码”的值。
   在占位提示为“请输入内容”的文本框中填写 SKU码。
   录制中稳定选择器：
   role=textbox name=请输入内容
   placeholder=请输入内容
   填写后确认输入框内的值与 Excel 一致。

5. 点击“查询”。
   录制中稳定选择器：
   role=link name=查询
   点击后等待商品列表刷新完成。
   如果查询不到商品，记录失败并跳过当前行。

6. 勾选目标商品。
   在查询结果中找到与当前 SKU码 完全匹配的商品行。
   勾选该商品行对应的 checkbox 或 input。
   录制中该步骤曾落到 css=input，实现时不要直接点击第一个 input。
   必须先定位到匹配 SKU 的商品行，再点击该行内的选择框。
   勾选后确认该商品已选中。

7. 点击“关联”。
   录制中稳定选择器：
   role=link name=关联
   点击后等待页面出现关联成功提示，或等待商品与视频绑定状态更新。
   只有确认关联成功，才认为当前 Excel 行处理成功。

8. 准备下一行。
   当前行处理完成后，根据下一行“视频地址”决定是否继续使用当前 use.html 页面、打开新的 URL、或回到起始页面上传/定位新视频。
   不要继承上一行的 SKU 输入值；每行查询前都应清空或覆盖输入框。

失败处理要求：
1. 每一行独立执行，单行失败不要中断整个 Excel。
2. 失败时记录：
   - 行号
   - SKU码
   - 视频地址
   - 当前执行步骤
   - 错误原因
   - 页面截图
3. 遇到以下情况不要继续盲目点击，先截图并记录原因：
   - SKU码 为空
   - 视频地址为空且当前页面不是 use.html
   - 视频地址为本地路径但文件不存在
   - 找不到“上传视频”按钮
   - 找不到 input[type=file] 或上传入口
   - 视频上传失败
   - 视频转码/处理超时
   - 无法进入 use.html 使用页面
   - 查询不到 SKU
   - 找不到 SKU 对应商品行
   - 商品勾选失败
   - 点击“关联”后没有成功提示
   - 页面出现登录失效、验证码、风控或异常弹窗
4. 不要依赖 css=button、css=input、css=a 这类模糊选择器作为首选。
   优先使用：
   - role
   - label
   - placeholder
   - 文本内容
   - 稳定 id
   - input[type=file]
   - 商品行内精确匹配 SKU 后再定位子元素
5. 所有关键操作后都要做结果确认，例如是否进入 use.html、SKU 是否填入、商品是否查询出来、目标商品是否已勾选、关联是否成功。
